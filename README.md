# CSS Display Properties — Homework

Open `index.html` in a browser and fix each broken layout by editing `style.css` only. Do not change the HTML.

---

## TODOs

- [ ] **Task 1** — Answer the three questions (Q1, Q2, Q3) as comments in `style.css`. No CSS to write.
- [ ] **Task 2** — Fix the vertical navigation so links sit side by side with equal width. Explain in a comment why `width` alone did not work before your fix.
- [ ] **Task 3** — Make the category tags flow inline while keeping vertical padding visible. Choosing `display: inline` will break the padding — pick a better value and explain why.
- [ ] **Task 4** — Find and remove the mysterious gaps between the `inline-block` boxes without touching margin or padding. Write the root cause as a comment.
- [ ] **Task 5** — Apply two different CSS properties: one that hides an element and collapses its space, one that hides it but keeps the space. Write a comment explaining the difference.
- [ ] **Task 6** — Build a side-by-side card row from scratch using only display properties (no flexbox, no grid). Cards must be 180px wide and top-aligned. Inline meta labels must sit on the same line.
- [ ] **Task 7 (Bonus)** — Recreate a two-column label/value layout using `display: table`, `table-row`, and `table-cell` — no `<table>` element allowed.

---

## Rules

- Edit `style.css` only.
- No flexbox (`display: flex`) or grid (`display: grid`) anywhere.
- Where a comment asks for an explanation, write it — it is part of the grade.
